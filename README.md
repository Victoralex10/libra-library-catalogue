# LIBRA — Library Catalogue

LIBRA is a library catalogue interface designed to support Library of Congress Classification (LCC), National Library of Medicine (NLM), Dewey Decimal Classification (DDC), Universal Decimal Classification (UDC), other/manual systems, and the proposed local LIBRA-FACET scheme.

## Deployment status
This repository has been created, but the application files still need to be added before Netlify can deploy the website.

## Next step

## Important
LIBRA-FACET is a proposed local scheme, not an official classification standard. Verify classification numbers against the appropriate official schedules.
